# Documentación del Proyecto Atlas

Esta carpeta contiene la documentación oficial del sistema Atlas, un sistema de gestión retail desarrollado para Joben's Moda.

## Contenido

- **Architecture/** — Arquitectura del proyecto, decisiones técnicas y estructura
- **ADR/** — Registro de Decisiones Arquitectónicas (Architecture Decision Records)
- **Audits/** — Auditorías técnicas del proyecto
- **Business/** — Reglas del negocio
- **Database/** — Documentación de la base de datos
- **Modules/** — Roadmap de módulos
- **Roadmap/** — Roadmap general del proyecto

## Propósito

Centralizar la documentación técnica y de negocio para mantener la trazabilidad de las decisiones, facilitar la incorporación de nuevos desarrolladores y preservar el conocimiento del proyecto.

## Convenciones

- Toda la documentación está escrita en español
- Se utiliza Markdown como formato estándar
- Los ADR siguen el formato propuesto por Michael Nygard
