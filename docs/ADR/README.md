# Architecture Decision Records

Este directorio contiene los Architecture Decision Records (ADR) del proyecto Atlas. Cada ADR documenta una decisión arquitectónica importante, incluyendo el contexto que la motivó, la decisión tomada y las consecuencias esperadas.

Se recomienda consultar estos registros antes de realizar cambios estructurales en el sistema para comprender las restricciones y fundamentos de la arquitectura actual.
